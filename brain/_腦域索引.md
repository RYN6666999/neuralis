## 三份地圖的分工

```
topology.yaml  →  執行期：邊現在通不通       →  probe.py 驗
causal.yaml    →  設計期：誰卡著誰           →  blast.py 查
drift.py       →  外部：不是我的東西動了沒   →  npm/GitHub API
```

判斷該寫哪份：
- 「A 呼叫 B 但斷了」→ `topology.yaml`
- 「A 沒做因為 B 沒建好」→ `causal.yaml`
- 「上游改了」→ `drift.py`（自動，不用寫）
