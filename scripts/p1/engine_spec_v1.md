# 房多多偏好引擎 — 引擎規範 v1（Ryan 2026-08）

## 第一性原理（原子，不可變）
- 每個人都同時有「渴望 D」與「怕 F」；行為是怕的包裝（攻擊/拖延/防衛遮蔽渴望）
- 人不會因「被說服/加強想」而動，只會因「預期失去降低」而動
- 「確認『是不是騙子』」本身就是「想信但怕失望」的證據（有渴望才會問）

## 生成模板（Ryan 確定的四拍母句）
1. 重定義（命名怕，先證表面不是）
   「其實不是[表面Q]，而是[真實的怕]，對嗎？」
2. 誠實讚賞（瓦解防衛，用「我的感受/觀點」而非斷言）
   「因為我看到你[具體的他對我的好]，而這是我的感受。」
3. 低門檻邀請（無法拒絕的小步）
   「所以[可以一起做的小事]，會不會比較簡單/安全/清晰？」

## 參數（學的東西，不學字面）
- 怕向量 F ∈ R^k：怕失去錢 / 怕受傷 / 怕孤單 / 怕被評判 / 怕決策錯 / 怕白費……
- 判怕：f_ψ(L) → F_hat（從語言估怕，樓回歸學）
- 選刀：W·F + b → 回應「重定義力度 w + 邀請步 a」
- 收尾：a ∈ {「比較不容易色/安全/清晰」}，A 由 F 維度映射

## 驗證（三條，非復盤）
- 冷啟動泛化：新 L → f_ψ 估 F，比 Ryan 真實 F（R² / 距離）
- 糾正次數遞減：同類怕新題 K_t 逐輪下降
- 判怕準（向量距離）> 閾值，不只看句子

## 心法
狠而短 → 修正在「瞬間判怕是哪維」，不是存句子。

## 執行控制流（Ryan 三句架構，最底層）
S1 重定義 → 逼對方二值表態：是/不是
S2 誠實讚賞 → 專破「不是」（讓他懷疑自己的否認）；是我感受非斷言，無從反駁
S3 低門檻邀請 → 逼二值表態：會/不會；無論何者＝已咬鉤，流程達標

控制流（只在二值空間跑，不辯論）：
  S1 → ans
     if ans==是 → S3
     if ans==不是 → S2（S2 讓他動搖後回 S1 或進 S3）
  S3 → 會/不會（任一達標）

關鍵：整個流程 = 操作「是/不是、會/不會」兩個二值表態，不含糊、不辯論。
