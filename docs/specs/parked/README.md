# parked — 凍結的 spec

這裡的檔案**不代表現況**。它們是設計稿、早期藍圖、或已被實作取代的計畫。
讀它們可以知道「當初想怎麼做」，不能拿來推論「系統現在長怎樣」。

**現況只有三個來源**（鐵律一：事實只能推導，不能複製）：

| 要知道什麼 | 去哪查 |
|---|---|
| 程式碼實際做了什麼 | 讀 `laap/` `scripts/`，或 `git log` |
| 系統活著沒、閘開沒 | `python3 scripts/aris-status.py`、`brain/lint.py`、probe |
| 最近發生什麼事 | Obsidian `Fun/Aris/留言板.md` |

## 凍結條件

一份 spec 進 parked，滿足其一：

1. **0 實作**且不在當前目標的依賴鏈上
2. 被實際程式碼**取代**（藍圖已經蓋成房子，藍圖就不是房子）
3. 計畫**已執行完畢**，留著只會被誤讀成待辦

## 解凍

要動裡面任何一份，先確認它描述的東西現在還成立，再 `git mv` 回 `docs/specs/`
並更新 frontmatter `status`。**不要原地照抄內容到新檔** —— 那是製造第二個會腐敗的抄本。
