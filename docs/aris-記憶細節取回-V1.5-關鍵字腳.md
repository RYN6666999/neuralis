# Aris 記憶 V1.5 — 中文關鍵字腳 + 修 200 字腰斬（給 Claude Code）

> 來源：Prime Agent · 代 Ryan 提出 · 2026-08-19
> 上一版 V1 的「只認數字」被 Ryan 否決：他要關鍵字，而且常貼整篇長文。
> Claude 你上一輪已經證明了「統計猜字」會失敗——**這一版不重蹈，走「對上就是對上」。**

## 兩件事

### 1. 開「中文關鍵字腳」（在 V1 的 _fetch_detail 上，另加一腳，不移除識別碼腳）
- **判準（寫死）**：問題拆詞後，**至少 2 個「有意義的詞」同時出現在同一筆 A庫記憶裡** → 該筆才算命中。
- 拆詞：jieba（做成 user-dict，把已知專名加進去：紫貘/龎家名/阿龐/阿龎/C單/富邦/中租/裕隆/聯徵等）。
- 濾掉停用詞（的/是/多少/最近/今天/哪裡/請/幫我 那類意義空洞的）。
- 排序：命中詞數 → 時間近 → flagged → total_recalls；LIMIT 2。跟 V1 同款，無相似度計分。
- 不引 LLM、不引向量、不引 tf-idf——**純字串包含 + 2 詞閾值**。
- 識別碼腳（V1 現有的數字/拉丁）保留並行：識別碼命中算單一強證據。

### 2. 修「200 字腰斬」
- `~/.hermes/scripts/aris-cognitive-hook.py` 的 `str(user_msg)[:200]`。
- Ryan 常貼整篇長文，後半段關鍵字全被砍掉 → 關鍵字腳白搭。放寬到能裝下正常長文（例如 4096），或至少把截斷點拉到不會砍掉關鍵字。

## 為什麼這條規則（你上一輪的「欠定」疑慮已解）
你上輪證明：374 筆小語料，用統計推「使用者問哪個」是欠定的。
但「**記憶裡真的出現了你講的詞**」不是統計——是對上就是對上。
實測（Prime 已跑過原型）：
- 「紫貘最近的數字」→ 命中紫貘那幾筆 ✅
- 「富邦銀行拒絕貸款」→ 命中 #1334 ✅
- 「C單的課程費用是多少」→ 命中 #1472（含 79,800）✅
- 「青鴉的代號是多少」→ **0 筆** ✅（庫裡無青鴉；單憑「代號」不撈——2 詞閾值修掉你上輪卡死的誤撈）
- 「上個月某客戶的融資利率」→ 撈到「哪個客戶？」那筆，幫她誠實答 ✅

## 驗收（沿用你上輪那份嚴格的，別退回）
換過的那套四條照用：答案只存在 A庫／問題夠具體／反面題一樣具體／事前驗地面真相。
外加一題整篇長文：先存一段含「富邦／中租／裕隆」的長文記憶，再問「那篇講融資的」，看關鍵字前後段都能撈到（驗證 200 腰斬有修）。

## 紅線（別破）
- 記憶沒出現你講的詞 → 一律不注入，她回「記憶裡沒有」。
- mode=ro、例外回 [] 且寫 log、不擋認知管線——這些 V1 已有，維持。
- 不因加關鍵字腳就把抗幻覺松開：沒有 2 詞交集就不算命中，沒有別的路。
